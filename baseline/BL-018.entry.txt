  - At frame 1208 (the first running frame) the two-player bit (byte $E6 bit 6) is clear: 1 player.
  - Frame 1140 (60 frames after the press): $81 = 00, $EC = 0c (they add up to 0c), $99 = 06, $C2 = 06. Byte $CC reads 00.
  - No joystick is touched; no ghost has caught Pac-Man by the end of the entry (frame 1399).
  - $99 and $C2 (60 frames after the press) equal the value measured in Stage C6 for game 8 (06).
  - How to check it against the real game: switch on, press Game Select 14 times (the status bar shows the game number), press Game Reset and do not touch the joystick.
