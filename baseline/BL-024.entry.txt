observations:
  Frames are counted from power-on (frame 0). Memory bytes are named by their address; the meanings are working labels
  (Stages C6 and C7, docs\CONTROLS.md and docs\CAPTURES.md), not yet confirmed (Phase F). Every number below was read from the trace.
  - Reset is pressed at frame 1800. At frame 1860: $81 = 07, which is 7 = (1860 / 256 rounded down), and $EC = 05 = 0c - $81.
  - Frame 1800: the lives counter (byte $98) reads 3: the game starts on frame 1800, the same frame the press began.
  - Frames 1800-1926: the pause flag (byte $D2, bit 6) is set while the start tune plays (127 frames, 2.1 seconds). Frame 1927: it clears and the game runs.
  - At frame 1927 (the first running frame) the two-player bit (byte $E6 bit 6) is clear: 1 player.
  - Frame 1860 (60 frames after the press): $81 = 07, $EC = 05 (they add up to 0c), $99 = 08, $C2 = 08. Byte $CC reads 00.
  - No joystick is touched. Frame 2224: the pause flag is set again: Pac-Man is caught and the death begins (297 frames after play began, 5.0 seconds).
  - Frame 2349: the lives counter changes from 3 to 2, 125 frames after the death began.
  - How to check it against the real game: switch on, wait about 30 seconds on the title screen, press Game Reset and do not touch the joystick.
